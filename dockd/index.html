dockd

High-performance application dock and window manager daemon for the Omarchy desktop environment and Hyprland.

v0.1.0 Zero Crates The Page Rule systemd-native Hyprland IPC Quickshell

Installation

1. Universal Web Installer (Recommended)

Installs the standalone release binary to ~/.local/bin/dockd, registers the native Omarchy Quickshell plugin, and configures systemd socket activation:

curl -fsSL https://ubermetroid.github.io/dockd/install.sh | bash

2. DNF / RPM (Fedora, RHEL, CentOS)

Install the native RPM package with automatic system service registration:

curl -fsSL https://ubermetroid.github.io/dockd/install.sh | bash -s -- --dnf

3. DEB / APT (Debian, Ubuntu)

Install the native Debian package via apt/dpkg:

curl -fsSL https://ubermetroid.github.io/dockd/install.sh | bash -s -- --deb

4. Arch Linux & Omarchy (PKGBUILD)

Build and install native Arch Linux package via makepkg:

curl -fsSL https://ubermetroid.github.io/dockd/install.sh | bash -s -- --pkgbuild

Getting Started

Once installed, enable the systemd socket activation unit and activate the dock in Omarchy:

# 1. Enable and start dockd via socket activation
systemctl --user enable --now dockd.socket

# 2. Enable the dock plugin in Omarchy
omarchy plugin enable org.ubermetroid.dockd

Command-Line Interface

The dockd binary acts as both the background daemon and an instant IPC controller:

# Query active dock items and state as JSON
dockd state

# Focus or minimize an application window by Hyprland address
dockd focus 0x55a3f120
dockd minimize 0x55a3f120

# Snap window to left or right half
dockd tile 0x55a3f120
dockd float 0x55a3f120

# Pin or unpin applications
dockd pin firefox.desktop
dockd unpin firefox.desktop

# Reorder pinned applications
dockd reorder firefox.desktop 0

# Filter dock windows by monitor ID (or 'all' for global view)
dockd monitor 0
dockd monitor all

# Switch layout profile preset (general, windows, mac)
dockd profile windows

Clean Uninstaller

Cleanly remove all binaries, systemd units, sockets, and Omarchy plugins:

# Via installed CLI helper:
dockd-uninstall

# Via web uninstaller:
curl -fsSL https://ubermetroid.github.io/dockd/uninstall.sh | bash

# Complete purge (including pinned app configuration):
dockd-uninstall --purge
# or: curl -fsSL https://ubermetroid.github.io/dockd/uninstall.sh | bash -s -- --purge
